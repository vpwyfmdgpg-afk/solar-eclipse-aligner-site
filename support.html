Thank you for using Solar Eclipse Aligner.

Getting Started

Solar Eclipse Aligner provides a four-step workflow:

  1. Import an eclipse image sequence.
  2. Analyze the solar disk and camera movements.
  3. Review and adjust alignment.
  4. Export aligned images or video.

Sample Project

The included sample project can be used to explore the analysis and alignment workflow. Some export or saving functionality may be unavailable when using the bundled sample.

File Access

Solar Eclipse Aligner only accesses photographs and folders selected by the user.

Need Help?

If you experience a problem, please include:

  • Your device model
  • Your iOS, iPadOS, or macOS version
  • Your Solar Eclipse Aligner version
  • A short description of the problem
